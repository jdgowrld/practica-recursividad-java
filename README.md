# Práctica de Recursividad - Estructuras de Datos

Implementación iterativa y recursiva de algoritmos matemáticos en Java, midiendo tiempos de ejecución (ms) y cantidad de iteraciones/llamadas.

## Algoritmos Implementados
- Factorial
- Serie de Fibonacci
- Máximo Común Divisor (Algoritmo de Euclides)
